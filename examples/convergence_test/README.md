# Convergence Test Suite for DOPAMINE

## Overview

This suite tests the spatial and temporal order of accuracy of the DOPAMINE solver using manufactured solutions and reference solutions.

## Requirements

- **gmsh** (for automatic mesh generation)  
  `apt-get install gmsh` or `brew install gmsh`

- **Python 3** with packages:
  - `numpy` (for computation)
  - `netCDF4` (for actual L2 error computation)  
    `pip install netCDF4`
  - `matplotlib` (for convergence plots)  
    `pip install matplotlib`

- **DOPAMINE** built with PETSc and NetCDF support

## Test Cases

### 1. Spatial Order Test (`spatial_convergence/`)
- **Problem**: 3D decaying Taylor-Green vortex
- **Domain**: [0, 2*pi] × [0, 2*pi] × [0, 2*pi] periodic (structured hex mesh)
- **Resolutions**: 16 x 16 x 16 (4K), 32 x 32 x 32 (33K), 64 x 64 x 64 (262K), 128 x 128 x 128 (2M) cells
- **Duration**: t = [0, 0.5] (short, fast decay)
- **Viscosity**: nu = 0.01 (Re = 200)
- **Mesh generation**: Automatic via `generate_meshes.py` (requires gmsh)
  - Creates structured periodic cubic hex meshes
  - Template based on `examples/taylor_green/taylor_green.geo` (proven, optimized)
  - Uses transfinite lines/surfaces for uniform grid quality
  - DOPAMINE reads gmsh format directly on first run
- **Method**: 
  - Run simulations at multiple 3D grid resolutions
  - Keep dt small (negligible temporal error)
  - Compute L2 error vs reference (finest) solution
  - Measure spatial convergence rate (expect order ~ 2)

### 2. Temporal Order Test (`temporal_convergence/`)
- **Problem**: Same 2D Taylor-Green vortex
- **Domain**: [0, 2*pi] × [0, 2*pi] periodic  
- **Duration**: t = [0, 0.5]
- **Method**:
  - Use fine grid (256 x 256) to minimize spatial error
  - Vary timestep dt
  - Compute L2 error vs reference (smallest dt)
  - Measure temporal convergence rate

### 3. Coupled Test (`coupled_convergence/`)
- Vary both dx and dt simultaneously
- Identify which error (spatial vs temporal) dominates

## Expected Orders of Accuracy

| Scheme | Spatial | Temporal |
|--------|---------|----------|
| CENTRAL + RK3W | 2nd order | 3rd order |
| KOREN_TVD + RK3W | 2nd order (TVD) | 3rd order |

## Running the Tests

### Spatial Convergence Test

```bash
cd spatial_convergence

# The script automatically generates meshes on first run, then runs convergence tests
bash run_convergence.sh

# (Optional) Manually pre-generate meshes:
# python3 generate_meshes.py       # Generates mesh_32x32.msh, mesh_64x64.msh, etc.
```

### Analyze Results

```bash
cd ../..

# Plot spatial convergence
python tools/convergence_analysis.py examples/convergence_test/spatial_convergence/results.csv \
  --title "Spatial Order of Accuracy" \
  --output spatial_convergence.png

# Plot temporal convergence (when available)
python tools/convergence_analysis.py examples/convergence_test/temporal_convergence/results.csv \
  --title "Temporal Order of Accuracy" \
  --output temporal_convergence.png
```

## Output Files

- `results.csv`: L2 errors at each refinement level
- `run_16.log`, `run_32.log`, etc.: Simulation logs for each resolution
- Convergence plots: Generated by `tools/convergence_analysis.py`

## L2 Error Computation

**Implemented**: Actual L2 error computation from DOPAMINE output

**Method:**
1. Read NetCDF output file (`.nc`) from DOPAMINE
2. Extract final velocity field and cell coordinates
3. Compute exact Taylor-Green solution at cell centroids
4. Compute L2 norm: `L2 = sqrt( sum((u_numerical - u_exact)²) / n_cells )`

**Exact solution** (2.5D Taylor-Green vortex):
```
u(x,y,z,t) = sin(x)*cos(y)*cos(z)*exp(-2*nu*t)
v(x,y,z,t) = -cos(x)*sin(y)*cos(z)*exp(-2*nu*t)
w(x,y,z,t) = 0
```

**Fallback**: If netCDF4 Python library is unavailable, uses mock error values (still allows convergence analysis to proceed)

## Interpretation

For spatial convergence (log-log plot):
- Slope ~ 2: 2nd order spatial discretization
- Slope < 2: Insufficient grid resolution; temporal/pressure error dominates
- Slope > 2: Super-convergence (rare; check if temporal error is negligible)

For temporal convergence:
- Slope ~ 3: 3rd order time integration (RK3W)
- Slope ~ 1: Dominated by spatial error; use finer grid
- Slope < 3: Pressure solver tolerance or grid too coarse

cd examples/convergence_test/spatial_convergence

Expected output: Log-log plot showing convergence order p ~ 2.0 with R-squared > 0.99 for 2nd-order spatial discretization
